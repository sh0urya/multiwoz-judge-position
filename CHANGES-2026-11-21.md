# Changes on Nov 21, 2026

No experiment code, prompts, data, or run logs were changed, and nothing was re-run.
Everything in `overnight/`, `results/`, `prompts/`, `data/`, and the top-level `*.py` files is exactly as before.

## Added

| Path | What it is |
|---|---|
| `analysis/recheck.py` | Re-analysis of `overnight/full`. Computes distinct-control false alarms, any-flag rates, and per-position flag rates and score drops with 95% bootstrap CIs (4,000 resamples of the 40 source goals). Also covers the later-restatement check and J3 flags on unchanged turns. |
| `analysis/lenient.py` | Evidence match using containment instead of exact strings. Also counts J3 later flags that re-quote the wrong value. |
| `analysis/out/*.json` | Outputs of both scripts, i.e. the source of every new number in the revised milestone. |

Rerun the analysis from the `analysis/` folder:

```bash
python3 recheck.py ../overnight/full out
python3 lenient.py ../overnight/full
```
